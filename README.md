# 🚀 InsureAI – Corporate Policy Automation and Intelligence System

## 📌 Overview

InsureAI is a full-stack web application designed to simplify and automate insurance policy management. The system provides a secure, role-based platform where customers, employees, agents, and administrators can efficiently manage insurance policies, claims, and related services.

The application is built using **Spring Boot** for the backend, **React.js** for the frontend, and **MySQL** as the database. It follows a RESTful architecture, enabling secure communication between the frontend and backend while ensuring scalability and maintainability.

# 🚀 Getting Started

## Prerequisites

* Java 17 or later
* Node.js
* npm
* MySQL
* Maven
* Git

---

## Backend Setup

1. Clone the repository.
2. Configure the MySQL database in `application.properties`.
3. Run the Spring Boot application using Maven or your IDE.

---

## Frontend Setup

1. Navigate to the frontend directory.
2. Install dependencies:

```
npm install
```

3. Start the React application:

```
npm start
```
